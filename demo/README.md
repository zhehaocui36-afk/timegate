# TimeGate 网页原型（demo）

> **这是原型，不是最终 App。**

## 这是什么

一个零依赖的单文件网页原型（`index.html`），完整演示「打开受管应用前先问三句」的交互：时长 → 意图 → 替代 → 计时 → 到时三出口，外加首次引导、四 Tab、构成环、统计与专注。

数据存在浏览器 `localStorage`，**它不能真的拦截你手机上的其他应用**——真拦截需要 Android 原生权限，见仓库的 Android 工程（`app/`）。

## 怎么用

- **双击 `index.html`** 即可打开，无需安装任何东西、无需构建。
- 或部署到 GitHub Pages（`demo/` 是 Pages 的静态源目录，见 `.github/workflows/pages.yml`）。

**演示路径**：我的 → 时间加速 60× → 应用 → 点一个应用 → 选时长 → 写理由 → 选替代 → 「还是想打开」→ 几秒后弹「时间到」。

**跳过引导**：URL 后加 `?nointro=1`。

## 边界

- 只读参考：它是 Android 版的设计参照物，**不再加功能**（见 `docs/OWNERSHIP.md`）。
- 非官方复刻：交互机制来自何同学 2021 年的「时间锁」，本项目为独立重写，不复用其代码与资源。
- 配色 `#5B6CFF`、无「每日总预算」、三问不可关闭——这些是已冻结的产品决策，不要改。
