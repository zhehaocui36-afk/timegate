# 闸 · TimeGate

> 打开之前，先想一下。

一个帮你在打开手机应用之前**停一秒**的工具。复刻自何同学 2021 年的「时间锁」，重做了界面与交互。

原来的「时间锁」在 2021 年做过一次 40 人实验：五种戒手机方法里，只有"打开前先问一句"这一种让使用时间下降了 **41%**（其余四种在 7%–16% 之间）。它后来停止维护了——没有暗色模式、教程是几个指向已下线服务器的外链、文案里还留着「第一个模块」这种占位符。

这个项目想把那 41% 重新做对。

## 当前状态

**可交互原型（Web），Android 原生版在计划中。**

现在仓库里是一个零依赖的网页原型：完整的闸门流程、计时、统计、设置都能真实操作，数据存在浏览器本地。它**不能真的拦截你手机上的其他应用**——那需要 Android 原生权限。

Android 方案、权限说明、实现要点见 **[HANDOFF.md](HANDOFF.md)**（唯一权威的交付文档）。

想直接看效果，双击 **[demo.html](demo.html)** —— 单文件、65KB、零依赖，双击即开。

## 现在就试

**方式一**：直接打开 `index.html`（双击即可，无需安装任何东西）。

**方式二**：仓库开启 GitHub Pages 后访问 `https://<你的用户名>.github.io/<仓库名>/`，手机扫码即可。

**方式三**：把页面加到手机主屏，全屏运行，体验接近原生。

第一次打开会走三步引导（教程 → 授权 → 选应用），走完才进首页。建议在「我的」里把时间加速调到 **60×**，再点一个应用，5 秒就能看完整个闭环。

## 交互

```
点开受管应用
   ↓
时长弹窗    5 分钟 / 15 分钟 / 自定义（底部常驻「直接退出」）
   ↓
第 2 问     你打开它想做什么？（写满两个字才能继续）
   ↓
第 3 问     放下它，你能先去做什么？
   ↓
使用中      倒计时，剩 1 分钟提醒
   ↓
时间到      主按钮「退出」｜小字「再继续使用一会儿」｜「转去专注 10 分钟」
```

**几个刻意的设计**

- **时长在最前面**。先定边界，再谈理由。反过来等于给他一个说服自己的机会。
- **「再继续」不是加 5 分钟**，而是回到时长弹窗重选。每次续，都要重新面对那三个数字。
- **没有"每日总预算"**。试过，没用——真正起作用的是"这一次用多久"，不是"今天还剩多少"。首页的环因此改成了**构成环**：每段颜色深浅代表一个应用占今天总时长的比例，只回答"时间花在哪了"。
- **不说教**。文案里没有"自律""坚持""加油"。

## 它不管什么

- 不做家长监督、好友 PK、云同步、账号体系
- 不上传任何数据（网页版连网络请求都没有）
- 不判断"好应用 / 坏应用"，只按你的选择执行

## 权限（Android 版）

| 权限 | 用途 | 不给会怎样 |
|---|---|---|
| `PACKAGE_USAGE_STATS` | 读每个应用今天用了多久 | 统计全是 0，无法判断是否到点 |
| `SYSTEM_ALERT_WINDOW` | 把提醒盖在别的应用上面 | 只能在通知栏提醒，容易划走 |
| `BIND_ACCESSIBILITY_SERVICE` | 点「退出」时把你送回桌面 | **可选**。不给就只做全屏遮挡，需要你自己按 Home |
| `FOREGROUND_SERVICE` | 锁屏、切走后继续计时 | 计时会中断 |
| `RECEIVE_BOOT_COMPLETED` | 重启后自动恢复监控 | 重启后要手动打开一次 |
| `POST_NOTIFICATIONS` | 到点提醒 | 没有提醒 |

**不声明 `INTERNET`。**

这不是"承诺不上传"，是**代码里没有联网能力**。原版声明网络权限只是为了加载在线 FAQ，而这里教程是内置的。

无障碍服务会自我限权：只订阅窗口切换事件、只读包名，**不读取任何屏幕文字**。这二十来行代码是可以直接审计的。

### 国产 ROM 注意（尤其 ColorOS）

Android 版上线后需要手动开启 5 项系统设置，否则会被厂商省电策略静默杀掉。ColorOS（OPPO / 一加 / realme）在国内属于最激进的几家，完整清单、三个专属坑和排查顺序见 **[HANDOFF.md 的 G.6 节](HANDOFF.md)**。

**网页原型不受影响**——用 Chrome 打开页面、加到主屏幕即可，不需要任何系统权限。

## 目录

```
.
├─ index.html          单页应用外壳
├─ css/
│  ├─ tokens.css       颜色、圆角、缓动
│  └─ app.css          组件与布局
├─ js/
│  ├─ store.js         本地存储与数据模型
│  ├─ gate.js          闸门状态机（时长 → 意图 → 替代 → 计时 → 到时）
│  └─ app.js           渲染、路由、设置、首次引导
└─ PLAN.md             完整设计与 Android 落地计划
```

数据存在 `localStorage` 的 `tg.state.v2`，跨天以**凌晨 4:00** 为界（0 点重置等于每天白送一份额度，而 23:50 恰恰是最典型的失控点）。
