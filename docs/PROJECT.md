## 定位边界（V1 写死，防止膨胀）

- Android only；不上任何商店。
- 无账号、无云同步、无埋点；零 `INTERNET`。
- 不做每日总预算、21:30 复盘推送、CSV 导出、多设备同步。
- 三问闸门不可做成可关闭开关；不引入 WebView。
