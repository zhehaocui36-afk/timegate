## 改了什么

在 S03 冻结的目录骨架上，建出**单模块 Gradle 工程 + CI**，干净克隆可构建一个空 Compose App。全部改动都在 S04 ownership 内，未越权触碰任何冻结/他人文件。

### 工具链（`gradle/libs.versions.toml` 为唯一版本入口）

| 项 | 值 | 说明 |
|---|---|---|
| Gradle | 9.6.0 | wrapper 锁定 |
| AGP | 9.5.0 | 最新稳定（2026-10） |
| Kotlin | 2.4.21 | **AGP 9 已内置 Kotlin**，此值只喂 Compose 编译器插件 |

### 关键架构决策（与 AGP 9 对齐）

- **不引入 `org.jetbrains.kotlin.android` 插件**：AGP 9 内置 Kotlin，加了会报 `Cannot add extension with name 'kotlin'`。
- **Compose 只用 `org.jetbrains.kotlin.plugin.compose`**（版本 = Kotlin 2.4.21），Compose 依赖由 BOM 管版本。
- **`jvmTarget` 未显式写**：AGP 9 内置 Kotlin 自动把 `jvmTarget` 对齐到 `compileOptions.targetCompatibility`（已设 17），无需 `kotlin { compilerOptions {} }`。

## 已知问题

1. **本地实跑已通过「底座」部分，待 S05 修完 2 处代码错误后重跑即可全绿**（2026-11-10 更新）：S04 工程底座（Gradle/SDK/依赖/Manifest/版本组合）实测正常；当前 `compileDebugKotlin` 失败是 S05 代码 2 个错误所致（见文末「给 S05 的验收反馈」）。修完后本地重跑一次 `assembleDebug lintDebug testDebugUnitTest` 确认全绿，再谈 CI。
2. **wrapper 二进制来源**：`gradle-wrapper.jar`/`gradlew`/`gradlew.bat` 因 `raw.githubusercontent.com` 被网络阻断，改从 `api.github.com`（`ref=v9.6.0`）拉取。与 `gradle wrapper` 命令生成的内容等价（同一 tag 的仓库原文件），但建议信任 `gradle-wrapper-validation` action 的复核结果。
3. **CI action 未固定 commit SHA**：SOP §11 E 要求第三方 action 固定 SHA。`ci.yml` 用的是 GitHub/Gradle **官方** action 的稳定 tag（`actions/*@v4`、`gradle/actions/*@v4`），非浮动第三方。`release.yml`（S14）会严格固定 SHA；如需更严，S12 审查 CI 时统一固定。
4. **SDK 组件依赖自动下载**：AGP 9.5 需要 `build-tools;36.0.0` + `platforms;android-37`，CI 上靠 ubuntu runner 预装 SDK + 已接受的 license 让 AGP 自动补装。若首跑报 `license not accepted`，在 ci.yml 加一步 `sdkmanager --licenses` 即可。
5. **`gradlew` 执行位**：仓库尚未 `git init`。`gradlew` 已本地 `chmod +x`，但 NTFS 不存 Unix 执行位；首次 `git add` 后需 `git update-index --chmod=+x gradlew` 固化，否则 CI 上 `./gradlew` 报 `Permission denied`（规避办法：CI 里用 `bash gradlew`）。
6. **临时启动图标**：`ic_launcher.xml` 是矢量占位（主色方块 + 白竖线），正式自适应图标由 S13 补。

## 给 S05 的验收反馈（2026-11-10 实跑发现，需 S05 修）

S04 实跑 `assembleDebug` 时 `:app:compileDebugKotlin` 失败，根因是 S05 代码 2 处错误（均属 S05 ownership，S04 不越权改）：

1. **`ui/theme/Color.kt` 第 18 行——嵌套注释陷阱（主根因）**：
   ```kotlin
    *    ui/components/** 一律通过 `TimeGateTheme.colors` ...
   ```
   注释文本里的 `ui/components/**` 被 Kotlin 当作**嵌套块注释的 `/*`**（Kotlin 支持嵌套注释），导致第 10 行的 KDoc 从此无法闭合，把 `TimeGateColors` / `DarkTimeGateColors` / `LightTimeGateColors` / `DarkColorScheme` / `LightColorScheme` / `LocalTimeGateColors` 全部吞进注释，引发几十条 `Unresolved reference`。
   **修复**：把 `ui/components/**` 里的 `/**` 拆开，例如改成 `ui/components/ *`（`/` 与 `**` 之间加空格）或写成「ui/components 包」。

2. **`ui/theme/Shape.kt` 第 7 行——import 写错包**：
   ```kotlin
   import androidx.compose.ui.graphics.CircleShape   // ✗ 这个包下没有 CircleShape
   ```
   `CircleShape` 在 `androidx.compose.foundation.shape`。
   **修复**：改成 `import androidx.compose.foundation.shape.CircleShape`。

修复后重跑 `./gradlew clean assembleDebug lintDebug testDebugUnitTest`（环境已就绪，见「怎么验」）。
