## 改了什么

### 1. `domain/time/**`（纯 Kotlin，零 `import android.*`）

| 文件 | 内容 |
|---|---|
| `DayKey.kt` | 4:00 换日：`dayKey = 本地日期(ts − 4h)`；`of(epochMillis, zone)` / `today(zone, nowMillis)` |
| `Clock.kt` | `Clock` 接口（`nowMillis()` + `zone()`），业务只经它取时间 |
| `SystemClock.kt` | 生产实现：`System.currentTimeMillis()` + `ZoneId.systemDefault()` |
| `RemainingTime.kt` | 剩余现算：`remainingSeconds` / `elapsedSeconds`，只存时间戳不存剩余秒 |

删除 `domain/time/.gitkeep`。

### 2. `data/local/**`（Room）

| 文件 | 内容 |
|---|---|
| `AppPolicyEntity.kt` | 受管应用（主键 package_name） |
| `UsageSessionEntity.kt` | 使用会话（started/left/ended 三时间戳，无剩余秒字段） |
| `GateLogEntity.kt` | 闸门日志（outcome 枚举：PASSED / 三类 ABANDONED） |
| `FocusSessionEntity.kt` | 专注会话（25 / 10 分钟） |
| `DaySummaryEntity.kt` | 每日汇总（day_key 主键 + total_minutes） |
| `GateOutcome.kt` | 闸门结果枚举 |
| `Converters.kt` | `GateOutcome ↔ String` TypeConverter |
| `AppPolicyDao.kt` / `UsageSessionDao.kt` / `GateLogDao.kt` / `FocusSessionDao.kt` / `DaySummaryDao.kt` | 五表 DAO |
| `TimeGateDatabase.kt` | `@Database`（5 entity，version 1，exportSchema）+ `getInstance(context)` + `destroy(context)`（删库重建） |

### 3. `data/repo/**`（接口 + 实现 + Fake）

| 文件 | 内容 |

| `FakeTimeGateRepository.kt` | 内存 Fake（`MutableStateFlow`），预览 / 单测替换用 |
