### 2. 关键设计决策

- **配色**：深色 `bg #000000 / surface #1C1C1E / tint #4E5CEC · tint-on #5B6CFF / danger #FF453A / warn #FF9F0A / btn-solid #FFFFFF`；浅色 `bg #F2F2F7 / surface #FFFFFF / tint #4655DB · #3541C9 / danger #FF3B30 / warn #C77700 / btn-solid #000000`。**主 tint `#5B6CFF` 未改动**。所有色值只在 `Color.kt` 出现。
- **双通道取色**：能映射进 Material3 的走 `MaterialTheme.colorScheme`（`cs.primary = tintOn`、`cs.background`、`cs.onSurface = textPrimary` …）；其余语义色走 `TimeGateTheme.colors`。满足「一律走 MaterialTheme 的 token」且完整覆盖 demo 变量。
- **tint 只允许 5 处**（`DESIGN.md` §4 写死）：① Tab 选中 ② 开关打开 ③ 环形分段 ④ 图表/数据条 ⑤ 可点文字与选中态（含 `--tint-soft` 焦点环）。其余全部黑白灰。
- **玻璃**：`半透明渐变面 + 顶部 1dp 高光线 + 底部 1dp 暗边 + 0.5dp 描边`，**无 `backdrop-filter`、无 `Modifier.blur`**。
- **组件全部 Foundation 自绘**，不套用 Material3 组件默认外观。

### 3. 三种「不崩」如何落地

| 情况 | 实现 |
|---|---|
| 深/浅切换 | `TimeGateTheme(darkTheme = …)` 同时切换两套 `TimeGateColors` + 两套 `ColorScheme`；组件零本地颜色 |
| 字号 200% | 字号/行高全 `sp`，`TimeGateTheme` 不覆盖 `LocalDensity`；容器只用 `heightIn` / `wrapContentHeight`，不设 `maxLines=1` / Ellipsis；Sheet 可滚动；Ring 中心文字 `wrapContentSize(unbounded=true)` 不裁切 |
| 减弱动效 | 默认读 `Settings.Global.ANIMATOR_DURATION_SCALE == 0`；`reduceMotion=true` 时所有 spec → `snap()`、`allowDisplacement=false` → 按压 scale 恒 1f、Sheet `translationY` 恒 0f，指示器/拇指瞬时到位（无中间位移动画） |
