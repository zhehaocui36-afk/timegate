# 闸 · TimeGate — 复刻计划（过程稿）

> ⚠️ 本文件是设计过程稿。**最终交付以 [HANDOFF.md](HANDOFF.md) 为准**，两者冲突时听 HANDOFF。

> 复刻何同学「时间锁」的核心机制（打开前先问），重做界面与交互。
> 交付形态：**零依赖静态网页原型**（手机浏览器 / 加到主屏）。真机拦截是二期 Android 工程，不在本次范围。

---

## 一、已确认的决策

| 项 | 决定 |
|---|---|
| 时长档位 | **5 分钟 / 15 分钟 / 自定义（1–120）** |
| 每日总预算 | **不做**，整个功能删除 |
| 专注模式 | **保留**，从首页进，也在到时页留一个入口 |
| 闸门顺序 | **先弹时长弹窗，再三问**（时长本身是第 1 道闸） |
| 到点出口 | **主按钮「退出」+ 小字「再继续使用一会儿」**；再继续 = 回到时长弹窗重选 |
| 底部导航 | 4 个 Tab：今日 / 应用 / 统计 / 我的 |
| 主题色 | 近纯蓝 `#5B6CFF`（深）/ `#3541C9`（浅），占比 <5% |
| 背景 | 纯色 `#000000` / `#F2F2F7`，无渐变无色斑 |

## 二、完整流程

### 首次配置（只做一次，装完强制走完）

```
安装 → 教程（3 屏）→ 授权（3 项）→ 选受管应用 → 完成
```

1. **教程第 1 屏**：这个 App 做什么（打开前先问三件事）+ 隐私承诺（不联网、不上传、无账号）
2. **授权第 2 屏**：三张卡片，逐项「开启」——使用情况访问 / 显示在其他应用上层 / 后台运行。三项全绿才能继续。
3. **选应用第 3 屏**：内置应用列表，默认勾选耗时最多的 3 个，可增减（至少留 1 个）。
4. 完成 → 进首页。

> 教程必须在选应用**之前**，不能跳过。原 App 的死穴就是"先让你用，用不了了才告诉你缺权限"。

### 日常（每次打开受管应用）

```
① 点开受管应用
      ↓
② 时长弹窗（sheet，底部常驻「直接退出」）
   5 分钟 / 15 分钟 / 自定义
      ↓ 继续
③ 第 2 问：你打开它想做什么？   （≥2 字才能继续）
      ↓
④ 第 3 问：放下它，你能先去做什么？  「我先去做」/「还是想打开」
      ↓ 还是想打开
⑤ 进入应用，倒计时开始（剩 1 分钟预警）
      ↓ 归零
⑥ 全屏「时间到」
   ├─ 主按钮「退出」 → 退出应用回桌面
   ├─ 小字「再继续使用一会儿」 → 回到 ② 重新选时长
   └─ 更小的字「转去专注 10 分钟」 → 进专注
```

**为什么时长在前**：先定"边界"，再谈"理由"。反过来问完理由才让他选时长，等于给了他说服自己的机会。

## 四、设计系统

### 颜色（Apple 语义色）

| 语义 | 深色 | 浅色 |
|---|---|---|
| 底 | `#000000` | `#F2F2F7` |
| 卡片 | `#1C1C1E` | `#FFFFFF` |
| 次级面 | `#2C2C2E` | `#E9E9EE` |
| 主 / 次 / 三级文字 | `#FFF` / `rgba(235,235,245,.60)` / `.34` | `#000` / `rgba(60,60,67,.60)` / `.34` |
| tint（填充） | `#4E5CEC` | `#4655DB` |
| tint（文字/图标） | `#5B6CFF` | `#3541C9` |
| 危险 | `#FF453A` | `#FF3B30` |

**tint 只出现在 5 处**：tab 选中、开关、环形分段、图表、可点文字。其余全是黑白灰。

### 圆角

`8 / 10 / 12 / 16 / 22 / 999`。卡片 12（iOS 分组卡片就是 10–12），弹窗顶部 28。

### 玻璃

只有两处真用 `backdrop-filter`：**底部悬浮胶囊**、**弹窗遮罩**。其余是"仿玻璃"（实色 + 顶光 + 暗边），因为在纯色底上开 blur 没有意义。

底部导航 = 两层玻璃：
- 外层胶囊：`blur(30) saturate(180%)` + 顶部 1px 高光 + 底部内阴影 + `.5px` 外描边 + 两端径向折射
- 内层选中胶囊：`rgba(255,255,255,.13)` + `blur(10)`，比外层亮一档

「玻璃通透度」滑杆映射 `--glass-blur`（4–32px）与 `--glass-alpha`（.85–.35）。

### 动效

| 场景 | 参数 |
|---|---|
| 按钮按下 | `scale(.972)`，90ms，绑 `pointerdown` |
| 选中胶囊移动 | `translateX` + `cubic-bezier(.34,1.4,.64,1)`，420ms |
| 弹窗上滑 | `translateY(100%) → 0`，420ms 弹簧 |
| 数字/柱图 | 400–600ms，只在值变化时写 DOM |

## 五、数据模型（localStorage `tg.state.v2`）

```js
{
  v: 2,
  settings: { theme, glass, speed, haptic, onboarded },
  apps: [{ id, name, short, quota, used, on }],   // used = 今日分钟数
  history: { 'YYYY-MM-DD': 总分钟 },
  gates: { total, abandoned },                     // 漏斗
  focus: { count, min }
}
```

- 跨天用**凌晨 4:00** 分界（`dayKeyOf(ts) = 本地日期(ts - 4h)`）。0 点重置等于每天白送一份额度，而 23:50 是最典型的失控点。
- **禁用** `toISOString().slice(0,10)`（那是 UTC，东八区偏 8 小时）。
- 计时只存时间戳，不存"剩余秒数"；页面回前台按时间戳补算。

## 六、权限与合规

| 能力 | 需要的权限 | 用户怎么给 | 要 root？ | 合规风险 |
|---|---|---|---|---|
| 读各 App 使用时长 | `PACKAGE_USAGE_STATS` | 设置里手动开「使用情况访问」 | 否 | 中，商店要申报用途 |
| 提醒盖在别的 App 上 | `SYSTEM_ALERT_WINDOW` | 手动开「显示在其他应用上层」 | 否 | 中 |
| 后台持续计时 | `FOREGROUND_SERVICE` + `specialUse` | 安装即得 | 否 | 低 |
| 开机自启 | `RECEIVE_BOOT_COMPLETED` | 安装即得 | 否 | 低 |
| 通知 / 震动 | `POST_NOTIFICATIONS` / `VIBRATE` | 首次弹窗 | 否 | 低 |
| 列出可管理应用 | `<queries>` 声明 LAUNCHER intent | 清单里写 | 否 | 低（比 `QUERY_ALL_PACKAGES` 干净） |
| 省电白名单 | `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 引导跳转 | 否 | 中，Play 有政策限制 |
| **点「退出」自动回桌面** | **`BIND_ACCESSIBILITY_SERVICE`** | 手动开无障碍 | **否** | **高** |
| 强制停止目标 App | `FORCE_STOP_PACKAGES` | 拿不到 | **是** | 不可行 |
| 真正阻止 App 启动 | 无公开 API | — | **是** | 不可行 |

**三条必须知道的结论**

1. **不需要 root 就能做到 95% 的功能**：统计、限额、提醒、遮挡、开机自启全部可行。
2. **「自动回桌面」卡在无障碍权限，不是 root**。Android 10+ 不允许第三方随便发 HOME intent，能做这件事的只有 `AccessibilityService.performGlobalAction(GLOBAL_ACTION_HOME)`。
3. **只有两件事需要 root / 系统签名**：强制停止别的 App、真正阻止 App 启动。第三方 App 只能"检测到它到前台了，立刻盖一层"。

**原 App 的一个坑**：它用 `killBackgroundProcesses()` 强杀目标 App，从 Android 10 起对**前台**应用无效，只能杀后台进程——所以在今天的手机上，那个"退出"很可能只是撤掉遮挡，App 还在。

**分发方式：只发 GitHub Releases，不上任何商店**

这一条直接改写了上面那张表的结论：

| 原来的顾虑 | GitHub 直发之后 |
|---|---|
| Google Play 会拒无障碍服务 | **不存在审核**。无障碍可以做，「退出即回桌面」能真正实现 |
| 商店要求隐私政策 / 权限申报 | 不要求。但 README 必须写清每项权限干什么——用户凭什么信你 |
| `QUERY_ALL_PACKAGES` 审核风险 | 不审核。但仍建议用 `<queries>` 收敛，省电也省心 |
| 软件著作权 / 备案 | 不需要 |

**可以再往前一步：不声明 `INTERNET` 权限。**
原 App 声明 INTERNET 只是为了用 WebView 加载在线 FAQ——服务器一关教程就废。我们的教程内置，所以能做到**零网络权限**。这是最硬的可信度证明：不是"我承诺不上传"，是**代码里根本没有联网能力**。

**无障碍权限的代价，必须写在明处。**
AccessibilityService 权力极大（能读屏、能点击），所以实现上要自我限权：

1. `accessibility-service` 配置只订阅 `typeWindowStateChanged`，`accessibilityFlags` 不申请 `flagRetrieveInteractiveWindows`；
2. 代码只取 `event.getPackageName()`，**绝不调用** `getText()` / `getContentDescription()`；
3. README 与 App 内各写一遍「它能看什么、不能看什么」，让任何人可以对着源码审计。

**默认策略**：无障碍是**可选增强**。不给，就退化成"全屏遮挡 + 提示"（iOS 屏幕时间就是这样）；给了，「退出」才真的能把你送回桌面。教程里要说清楚两者的区别，别用红字吓人，也别偷偷绕过。

## 八、二期 Android 要点

- **检测**：`UsageStatsManager.queryEvents` 2 秒轮询为主（授权门槛低），`AccessibilityService` 作可选增强（能提前 0–200ms 拿到前台包名），两路写同一 Repository 去重。
- **弹闸门**：用透明主题的 `GateActivity`，不要用悬浮窗（三问要输入文字，悬浮窗在输入法弹起时必崩）。注意 Android 10+ 后台启动 Activity 受限，**持有悬浮窗权限时才豁免**——所以悬浮窗权限不只是用来提醒，是能弹闸门的前提。
- **退出**：`performGlobalAction(GLOBAL_ACTION_HOME)`，需要无障碍；拿不到就只做遮挡。
- **Android 14 前台服务**：`foregroundServiceType="specialUse"` + `PROPERTY_SPECIAL_USE_FGS_SUBTYPE`。
- **ROM 适配**：按 `Build.MANUFACTURER` 跳小米/华为/OPPO/vivo 自启动页，失败降级图文步骤。
- **Room**：`app_policy` / `usage_session` / `gate_log` / `focus_session` / `day_summary`，日期存 `day_key TEXT`，不要存 `Date`。

## 十、发到 GitHub

**仓库结构**：`timegate/` 这个文件夹本身就是仓库根目录（`index.html` 在最外层），这样 GitHub Pages 零配置就能跑。

```
timegate/                ← git init 在这里
├─ index.html            ← Pages 入口
├─ README.md
├─ LICENSE
├─ .gitignore
├─ PLAN.md
├─ css/  js/
```

**两条发布通道**

| 通道 | 做法 | 用途 |
|---|---|---|
| GitHub Pages | Settings → Pages → Deploy from branch → `main` / `root` | 网页原型直接可访问，手机扫码就能试，无需装任何东西 |
| GitHub Releases | 打 tag `v0.1.0`，上传签名的 `app-release.apk` | Android 版分发。用户需在系统里允许"安装未知来源应用" |

**Release 三条纪律**
1. **keystore 泄漏 = 应用身份被劫持**。`*.jks` / `*.keystore` 必须进 `.gitignore`，签名密码放本地 `keystore.properties`（同样忽略）。
2. 每个 release 的 `versionCode` 必须递增，否则覆盖安装会失败。
3. Release notes 里写清楚「本版本新增了什么权限」——用户升级前有权知道。

**可选：F-Droid**
F-Droid 要求可复现构建、无跟踪器。我们这个"零网络权限"的设定天然符合，可以作为第二个渠道。但它对无障碍服务会加"Anti-Features"标记，需要接受。

**README 必须有的六块**
1. 一句话说明它做什么（以及它**不**做什么）
2. 当前状态（原型 / Android 版进度）
3. 每项权限的用途 + 不给会怎样
4. 隐私：零网络权限，可对源码审计
5. 安装步骤（Release APK + 未知来源；或 Pages 直接试）
6. 许可证

> 开源一个带无障碍权限的 App，**信任是靠透明度换来的**，不是靠 README 里写"请放心"。权限表 + 零 INTERNET + 可审计的二十行无障碍代码，比任何承诺都管用。
