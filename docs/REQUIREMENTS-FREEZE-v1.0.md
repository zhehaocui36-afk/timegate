## 01 范围与平台

- 只做 Android。iOS 没有分应用使用时长、也没有跨应用悬浮窗，**明确不做**。
- Kotlin + Jetpack Compose；`minSdk` 26，`targetSdk` 跟随当年最新。
- 零网络权限：不声明 `INTERNET`。无账号、无云同步、无埋点。
- 分发只走 GitHub Releases 的签名 APK，不上任何商店。
- **V1 不做**：每日总预算、21:30 复盘推送、CSV 导出、多设备同步、好友 PK。
- **冻结规则**：本页之后新增需求进 V1.1；新增任何权限必须写进 Release Notes。

## 02 首次配置（不可跳过）

教程 3 屏 → 权限（必需 5 项 + 可选 2 项）→ 选受管应用（至少 1 个）→ 首页。

- 教程必须在选应用**之前**；不能先让用户用，用不了才说缺权限。
- 每项权限都跳系统页，回来**回读真实状态**；演示里“点一下算授权”的做法必须删掉。
- 必需项缺失 → 不能继续；可选项缺失 → 允许继续，但用一句话说明后果。
- 选应用默认勾选耗时最多的 3 个【AI建议】。

## 03 日常主流程

点开受管应用 → 2 秒内检测到前台 → 弹闸门

1. **时长**　5 / 15 / 自定义 1–120　（第一道闸，先定边界）
2. **意图**　写满 2 个字才能继续
3. **替代**　我先去做 = abandoned　·　还是想打开 = 放行
4. **计时**　前台服务，剩 1 分钟预警
5. **归零**　全屏「时间到」
   - ├ 退出 → 回桌面（有无障碍）/ 撤遮挡（无）
   - ├ 再继续 → 回 ① 重选，不固定续杯
   - └ 转去专注 10 分钟

- 闸门每一步都有「直接退出」，记 abandoned，**不扣时长**。
- 顺序不可换：先定边界，再谈理由。

## 04 边界与口径

- 跨天用**凌晨 4:00**；`day_key` 用本地年月日拼，禁止 UTC 截断。
- 计时只存**时间戳**，不存剩余秒；回前台按离开时刻补算。
- 提前结束：按实际分钟计入，最少 1 分钟。
- 意图不足 2 字：继续按钮禁用，不弹错误弹窗。
- 连续「再继续」：V1 允许，只记日志，不做惩罚与冷却。
- 检测失败（拿不到前台包名）：不弹闸门，只记日志，**不阻塞用户**。

## 05 数据（Room）

`app_policy` · `usage_session` · `gate_log` · `focus_session` · `day_summary`

- 日期存 `day_key TEXT`，不要存 `Date`。
- 清空数据 = 删库重建，不做软删除、不做云备份。
- V1 单机；导出 CSV / JSON 进 V1.1。

## 06 权限矩阵与降级

**必需 · 缺一不可**

| 权限 | 不给的后果 |
|---|---|
| 使用情况访问 `PACKAGE_USAGE_STATS` | 统计全 0，闸门不触发 |
| 悬浮窗 `SYSTEM_ALERT_WINDOW` | 闸门弹不出（也是后台弹页前提） |
| 通知 `POST_NOTIFICATIONS` | 无法常驻、无法预警 |
| 前台服务 `FOREGROUND_SERVICE` + `specialUse` | 计时被系统杀 |
| 电池白名单 `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 息屏几分钟即失效 |

**可选增强**

| 权限 | 不给的后果 |
|---|---|
| 自启动 `RECEIVE_BOOT_COMPLETED` | 重启后需手动打开一次 |
| 无障碍 `BIND_ACCESSIBILITY_SERVICE` | 退出只撤遮挡，回不了桌面 |

**清单与厂商**

- `<queries>` 声明 LAUNCHER，否则列表为空；ColorOS 另有「应用列表」开关，关掉同样为空。

## 07 技术定死

- **检测**：`UsageStatsManager.queryEvents` 2 秒轮询为主；无障碍只作可选加速。
- **无障碍自我限权**：只订阅 `typeWindowStateChanged`，只读 `packageName`，不申请 interactive windows、不读屏幕文字。
- **闸门**：透明主题 `GateActivity`，不用悬浮窗——三问要输入，悬浮窗遇输入法必崩。
- **服务**：`START_STICKY` + 常驻通知；Android 14+ 用 `specialUse`。
- **退出**：`performGlobalAction(GLOBAL_ACTION_HOME)`；拿不到权限就只撤遮挡。
- **四页也用 Compose 重写**，不套 WebView：启动快、包体小、输入不被输入法打断；玻璃用半透明 + 顶部高光模拟，不追 `backdrop-filter`。

## 08 验收（Find X8 / ColorOS 17）

1. 强停后重开 → 前台服务能自己起来。
2. 息屏 10 分钟 → 回来倒计时准确，不是停在息屏那一刻。
3. 重启手机 → 通知栏里有常驻通知。
4. 打开受管应用 → 闸门能盖上去。
5. 到点 → 能拦截；有无障碍时「退出」能回桌面。
